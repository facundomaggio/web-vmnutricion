# VM · Nutrición deportiva

Primera versión estática del proyecto del curso. Basada en el proyecto del Cliente, adaptada a HTML y CSS separados.

## Archivos

- `index.html`: contenido y estructura de la página.
- `css/estilos.css`: colores, distribución y adaptación a celulares.
- `assets/img/`: logo, fotografía de portada de referencia e ilustraciones SVG sencillas.
- `referencias/stitch-original.html`: propuesta original, conservada para comparar. Contiene datos generados sin verificar y dependencias externas; no es la página principal.

## Abrir la página

Abrir esta carpeta en VS Code. Hacer clic derecho en `index.html` y elegir **Open with Live Server**, o abrir el archivo directamente en el navegador.

## Criterios de trabajo

- Avanzar por secciones y explicar los cambios según los temas del curso.
- Usar HTML y CSS propios, sin Tailwind ni herramientas de compilación.
- Agregar `js/main.js` cuando se empiece a trabajar con interacción en JavaScript.
- Todavía no hay formulario, almacenamiento ni base de datos.
- La navegación funciona con enlaces HTML. En celulares, los enlaces siguen visibles sin menú programado.
